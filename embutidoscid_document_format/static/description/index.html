Embutidos CID - Formato de Documentos

Módulo personalizado que extiende el formato de impresión de los albaranes de entrega para incluir toda la información de trazabilidad y datos económicos necesarios.

✨ Características Principales

📦 Información de Trazabilidad

  • Número de lote completo
  • Fecha de caducidad del producto
  • Datos completos de cada producto

💰 Información Económica

  • Precio unitario de venta
  • Porcentaje de descuento aplicado
  • Subtotal por línea
  • Resumen de totales con impuestos

📋 Información del Pedido

  • Referencia del pedido de venta
  • Referencia del cliente
  • Condiciones de pago

🚀 Funcionalidad

  • Se integra automáticamente con pedidos de venta
  • Calcula precios proporcionales a la cantidad entregada
  • Compatible con entregas parciales
  • Solo muestra datos económicos en albaranes con pedido asociado

📦 Dependencias

  • sale_stock - Integración ventas/inventario
  • product_expiry - Gestión de caducidad
