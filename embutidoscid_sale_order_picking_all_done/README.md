# embutidoscid_sale_order_picking_all_done

Módulo compatible con Odoo 19 Enterprise para confirmar, entregar y facturar
pedidos de venta en un clic.

## Funcionalidad

- Confirma pedidos de venta.
- Completa las entregas pendientes usando el flujo de stock de Odoo 19.
- Valida albaranes desde el pedido sin abrir manualmente la operación logística.
- Crea facturas regulares tras la entrega.

## Dependencias

- `sale_stock`
