Sale Order Lot Selection FEFO

Select and reserve the correct lot by expiration date from the sales order

Version19.0.2.0.0
CategorySales Management
AuthorDaniel Domínguez (xtendoo)
LicenseAGPL-3
Websitehttps://xtendoo.es

This module allows selecting a lot on the sale order line and propagates it to stock moves so the reservation and delivery use the chosen lot.

It also suggests the appropriate lot automatically using FEFO based on the expiration date when the product is changed on the sale order line.
